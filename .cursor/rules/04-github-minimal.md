# GitHub Minimal Mode (Token Saver)

- Do NOT list/search issues.
- Do NOT call GitHub APIs (no curl), do NOT comment, do NOT add/remove labels.
- Only read the single issue currently in progress IF it is already provided/linked by the user.
- If the issue number/title is not provided, ask the user to paste it (title + acceptance criteria) instead of fetching.
- All status moves/labels/comments are done by the user manually.
