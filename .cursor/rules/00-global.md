- Determinism is non-negotiable: all randomness through SeededRandomService.
- Keep Domain/Simulation free of Godot references.
- One issue at a time: only work on the issue currently in "In Progress".
- After finishing, produce a Review Packet:

  2) Files changed
  3) How to test in Godot (exact clicks)
  4) Risks/notes
- No scope creep: do not add features outside the current issue acceptance criteria.
